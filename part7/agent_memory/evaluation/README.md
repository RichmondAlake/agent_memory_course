# Evaluating agent memory

How do you know an agent's memory works? This notebook tests memory's four promises on three agents that answer the
same questions:

- **naive**: no memory store; the whole history goes into every prompt.
- **scratch Memo**: tables you build on Oracle AI Database. `MEMEVAL_TURNS` holds conversation rounds with
  `VECTOR(256)` and an Oracle Text index, found by hybrid search; `MEMEVAL_FACTS` holds entity facts that a newer
  value supersedes.
- **MemoRizz Memo**: the same agent on MemoRizz 0.17.8, with conversation memory recalled across threads and entity
  memory written through the model's tools.

| Part | Question | Measured by |
|---|---|---|
| 0 | Setup | models and prices, the LLM judge, Clef-Flash and Jev, Oracle, optional Arize AX tracing |
| 1 | What should we measure? | abilities vs operations; Wilson intervals and McNemar |
| 2 | Can we trust the graders? | 120 answers with known grades: κ per check for the judge, Clef-Flash and Jev; the cheapest grader that passes, with the judge for unsure answers |
| 3 | The three agents | one interface: `ingest`, `observe`, `answer` |
| 4 | Does it remember? | LongMemEval: accuracy per ability with intervals, McNemar, recall@10, tokens, p50/p95 latency, $ per answer |
| 5 | Does it keep up with changes, and keep secrets? | FactConsolidation stale answers; canaries across users and sealed threads; forgetting that reaches every copy |
| 6 | Is it ready to ship? | scorecard and release gates |

## Run the notebook

```bash
../../oracle.sh start                 # from this folder
jupyter lab notebook/agent_memory_evaluation.ipynb
```

It reads `OPENAI_API_KEY`, `ANTHROPIC_API_KEY` (the judge; optional) and `TYPESAFE_API_KEY` (Jev; optional) from the
environment or `appbook/.env`, and asks for them otherwise. Clef-Flash runs in the notebook's process (MLX on Apple
silicon, about 7 GB; PyTorch in 4-bit on an NVIDIA GPU) unless `CLEF_URL` points at a SystemOne endpoint serving it.
The sizes are environment variables: `MEMEVAL_LME_PER_TYPE` (5), `MEMEVAL_LME_ABSTENTION` (6), `MEMEVAL_LME_TOKENS`
(20000), `MEMEVAL_FC_QUESTIONS` (40).

A run keeps what it wrote: the scratch Memo's rows, both MemoRizz agents with their memories and trace bundles, and its
evidence in `MEMEVAL_RUNS`, `MEMEVAL_RESULTS`, `MEMEVAL_GRADES` and `MEMEVAL_GATES`, where the appbook lists it. Its
traces appear in the MemoRizz UI (Traces, filtered by agent) when the UI reads this schema, which needs MemoRizz's
`oracle` extra (for example `memorizz[ui,oracle]`), and in Arize AX when `ARIZE_SPACE_ID` and `ARIZE_API_KEY` are set.
`MEMO_CLEANUP=1` deletes the run's rows; `MEMEVAL_DROP_RUN=1` also deletes its evidence.

**No API keys?** Press Enter at the OpenAI key prompt (or set `MEMO_PROVIDER=ollama`): the agents and the judge run on
Gemma 4 through [Ollama](https://ollama.com), the vectors on nomic-embed-text, and Clef-Flash grades locally. Expect
lower scores than the saved outputs, which come from the API path.

What the run shows:
- **LongMemEval.** MemoRizz's gap is not significant at n = 36 (McNemar p = 0.12 against each agent). Four of its six
  misses are single-session-assistant questions, and both Memos retrieved an evidence session for every answerable
  question.
- **Release gates.** MemoRizz's one failed gate varies from run to run: the previous run (`012009c8`) had no stale
  answers and both Memos were ready. Its p95 latency, 14.96 s, passes the 15 s gate with almost no margin.
- **FactConsolidation.** MemoRizz's three stale answers are the real-world values (English, American football, Satya
  Nadella), which the benchmark's counterfactual newer facts overwrite. Its write path filed 151 entities with 444
  attributes (the largest 63 KB), which 0.17.8 saves.
- **Forgetting.** `gpt-6-luna` filed Ada's hypothetical "If I were on the database team, I'd own the retrieval-api
  service too" as the scratch Memo's `user.owns`, which superseded "docs-search". Stage 2 deleted the turn naming her
  city, and the only remaining copy of docs-search went with it. A write error like this one shows only once forgetting
  removes the copy that was hiding it.
- **Second grader on LongMemEval.** The policy grader agrees with the judge on 94–100% of answers. All four
  disagreements are unanswerable questions graded by Clef-Flash outside the escalation band: the band does not
  catch confident errors.
